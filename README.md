Just a mod for Never ending legacy. 

To run: 

Click the version you want, then in the top right hit raw. Copy the link and paste it into the mods tab.

BACKUP:

Download the version you want, then copy colonies.js into the zip's Game folder (next to data.js and index.html). 
In that folder, run python -m http.server 8000, then open http://localhost:8000/index.html. In Use mods, enter:

data.js
colonies(V#.#.#).js
